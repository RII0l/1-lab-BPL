## Визуализация модели

Для отображения состояния транспортной системы используется двумерная клеточная сетка.

Каждая клетка поля может находиться в одном из трех состояний:

- `0` — свободная клетка;
- `1` — автомобиль, движущийся вправо;
- `2` — автомобиль, движущийся вниз.

Цветовая схема:

- белый — свободная клетка;
- синий — автомобиль, движущийся вправо;
- красный — автомобиль, движущийся вниз.

На рисунке отображается текущее состояние клеточного автомата на выбранном такте моделирования.

В заголовке рисунка выводятся:

- `ρ` — плотность автомобилей;
- `t` — номер текущего такта;
- `<v>` — средняя скорость автомобилей на данном такте.

Средняя скорость определяется как

$$
\langle v \rangle = \frac{M}{N}
$$

где:

- `M` — количество автомобилей, переместившихся за текущий такт;
- `N` — общее количество автомобилей в системе.

Значение `<v> = 1` означает, что все автомобили смогли переместиться.
Значение `<v> = 0` соответствует полной блокировке движения.

При работе в режиме анимации последовательно отображаются состояния

$$
F^0 \rightarrow F^1 \rightarrow F^2 \rightarrow \ldots \rightarrow F^T.
$$

Дополнительно программа автоматически сохраняет промежуточные состояния системы через заданное число тактов, например:

- `state_t_0050.png`
- `state_t_0100.png`
- `state_t_0150.png`
- `state_t_0200.png`
